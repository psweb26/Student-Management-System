# Student Management System

A full-stack Student Management System built using **Java, Spring Boot, MySQL, HTML, CSS, and JavaScript**.

## Features

- Student management and record handling
- REST APIs using Spring Boot
- MySQL database integration
- Separate frontend and backend
- API testing with Insomnia

## Tech Stack

- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** Maven, Git, Insomnia

## Project Structure

```text
Student-Management-System/
├── Backend/
│   └── studentmanagement/
├── Frontend/
└── Insomnia_.yaml

```

## Getting Started
1. Clone the repository
git clone https://github.com/psweb26/Student-Management-System.git
cd Student-Management-System
2. Configure MySQL

Update the database credentials in the Spring Boot configuration file.

3. Run the backend
cd Backend/studentmanagement
mvn spring-boot:run
4. Run the frontend

Open the files inside the Frontend folder using a local development server.

## API Testing
The included Insomnia_.yaml file can be imported into Insomnia to test the available APIs.
